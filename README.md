# MARG — Digital Future

Website for MARG, a studio that designs and builds websites, web apps and mobile apps.

Live site: https://mohamedraafat15112005-alt.github.io/marg/

Plain HTML, CSS and JavaScript. Animations use GSAP, ScrollTrigger and Lenis (loaded from jsDelivr); the background is a small WebGL shader in `scene.js`.
